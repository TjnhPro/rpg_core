## Ownership and API

Kernel owns the canonical rank factor, base/scaling products, flat addition,
ordered item-source products, B1 accumulation and double clamp. It exports three
new functions through `@rpg/core/kernel`: `calculateDamageB0`,
`calculateDamageB1`, `calculateDamageBonusValue`; and two new contracts:
`DamageB0Input<Source>`, `DamageB0Result<Source>`. Current inventory is **55 symbols,
46 types and nine runtime functions**, with 13 reachable declaration files.
The existing five v2.0.2 Damage contracts are unchanged.

Legacy retains all validation, context/source eligibility, modifier selection
policy, diagnostics, Dodge, Critical, Defense and snapshots. It delegates numerical
work to Kernel and continues using the canonical v2.0.4 Modifier Resolver. No
second modifier calculator was added. Stats, Defense, Modifiers, Skills, DoT,
resource code, package metadata and historical forwarders remain unchanged.

The landed-hit order remains:

1. Existing snapshot validation, modifier canonicalization and Defense hit resolution.
2. Dodge early return, with its original complete zero-result shape and no B0/Crit reads.
3. B0 reads perRank, rank, base, then ordered source/coefficient products.
4. `resolveFlat()` runs once after scaling, retaining Legacy scope/eligibility and
   canonical resolution; definition/input/resolved flat terms are read afterward.
5. Legacy constructs setting/item/canonical bonus diagnostics. Each item value is
   multiplied by a freshly read coefficient before accumulation, including the
   existing computation of ineligible items. Original source references remain live.
6. Legacy resolves Critical with the original lazy RNG, live chance/bonus reads,
   DoT bypass and error behavior.
7. B1 accumulates the already effective bonus records and selected additive Critical
   bonus, then applies the original two clamps; Legacy mitigates Defense and builds
   the same nested result.

Numerical accessors run synchronously; no Promise support, validation, cloning,
freezing or snapshot callback is added. Stable/pure caller policies give generic
determinism. Legacy deliberately adapts mutable live configuration to preserve its
historical invocation boundaries. TypeScript readonly does not detach/freeze data.
NaN/Infinity and native thrown objects propagate to the same existing boundaries.
