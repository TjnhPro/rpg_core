## Canonical and gameplay owners

Kernel owns the 17 public numerical/capture APIs under Stats, Modifiers, Damage,
Defense, Resources and Snapshots. The internal snapshot clone/freeze helper is a
source dependency, not a public API/declaration dependency. The existing symbol
audit checks 24 direct Legacy call occurrences, wrapper edges, the returned
modifier resolver, state writes, trust callers and authority stores.

Legacy keeps validation, conditions policy, modifier source activation, delivery/
entity eligibility, config adaptation, lazy RNG and diagnostics. Skills owns
admission, MP cost, action/deadline commitment and effect dispatch; Combat owns
canonical resource/action transitions; integration commits HP/MP results and
events. Root/Instance/Trigger keep their accepted capture/trust/session/receipt/
budget/replay/atomicity stores. Effects keeps lifecycle/DoT and Mechanics/Spatial
keep geometry. Lifesteal/percent requests, MP cost, rank policy, geometry and queue
budgets are gameplay arithmetic, not duplicate numerical calculators.

No production implementation changes. Preserved bytes, exact delegation mapping,
existing duplicate fingerprint checks and numerical/runtime regression provide
complementary evidence. They are not an exhaustive proof of semantic equivalence
for arbitrary future JS callbacks or differently written algorithms.

## Limitations and next gate

Static ownership is finite; accepted runtime observations cover dynamic callbacks
without claiming every possible caller graph. Consumers are numerical recipes,
not complete games or commercial formula fidelity. Existing harness cleanup
removes the temporary archive; the reviewer checks producer attestations, full
candidate file hashes and installation integrity, not an independently retained
archive. Raw local hashes and tarball identity are not portable source baselines.
