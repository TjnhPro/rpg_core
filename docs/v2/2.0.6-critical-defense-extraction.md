## Numerical and observation boundaries

Hit uses selected bounds: `max(min, min(max, dodgeChance))` when enabled,
eligible and chance is present, otherwise zero. Only positive chance consumes a
roll. A consumed roll must be finite in [0,1], with the original error
`Dodge roll must be0..1`; comparison remains strict `<`. Dodge invokes the
provided callback unbound, including after mutable-rule reads.

Eligible Critical draws before chance is read, even for zero chance. It clamps
chance with selected bounds, compares strictly `<`, and reads bonus only on
success as `max(0, bonus)`. It does not add roll validation. The multiplier is
only `1 + bonus` diagnostic; B1 uses the selected additive bonus directly.
The Legacy thunk retains the two original roll-property reads and original input
receiver. DoT skips all numerical input reads/RNG and maps public roll to `1`.
Dodge early return, B0-before-Critical and B1-after-Critical remain in place.

Mitigation computes positive level gap, optional level scaling,
`effectiveK = baseK * (1 + gap * levelPenalty)`,
`rawReduction = rating / (rating + effectiveK)` for positive rating/configured K,
then selected clamping. Kernel owns `finalDamage = damage * (1 - reduction)` and
`preventedDamage = damage - finalDamage`. Missing coefficients produce null K;
missing diagnostics remain ordered, and disabled status takes precedence.
Legacy maps only the generic missing-level label to `attacker/defender level`.
It preserves public field order, context identity and mutable diagnostic arrays.

The selected coefficients object is captured once. Fields on that captured
object, selected rule fields and actor levels remain live through accessors.
Replacing the coefficients container cannot replace the captured reference;
mutating its fields can affect later reads. Late diagnostics retain their own
original reads. Generic absent bounds are unbounded; explicit invalid values
from Legacy forwarding getters remain invalid rather than being normalized.

## Golden provenance and independent consumers

HEAD and clean source/baseline. It pins all 85 accepted TypeScript source blobs
by SHA-256, transpiles accepted Damage/Defense source in memory, and captures
150 observation scenarios, including 25 expected errors. The candidate
golden is static; tests never regenerate it from extracted code. No second
runtime calculator is shipped or kept in tests.

Observations compare exact nested numbers (including NaN/Infinity encodings),
object key order, RNG/getter traces, error type/message and short-circuit results.
Separate assertions verify unbound Dodge, receiver-preserving Critical, mutable
missing arrays, original context and original thrown-object identity. Existing
v2.0.3 mutation/stat, v2.0.4 modifier and v2.0.5 damage goldens remain unchanged.

Kernel-only consumers compile with strict NodeNext and execute installed native
ESM: Text RPG custom probability plus fixed fractional reduction; Vo Lam custom
rating key, levels and B0/B1; ARPG multiple selected rating policies. Text RPG
uses min=max fractional bounds, as approved. Exact floating-point results include
Vo Lam final damage `80.00000000000001`, prevented `39.999999999999986`.
