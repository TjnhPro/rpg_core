## Independent expectations and accepted-source trace provenance

Each expected file separates fixed hand-calculated `hand` vectors from
supplemental full `observations`. Full observations were captured explicitly
using only accepted Kernel Git blobs at the baseline, compiled in isolation.
The capture script checks every independently authored hand vector before
writing observations; it refuses implicit capture or overwriting provenance.
Tests and consumer verification never regenerate expected outputs. Accepted
source and caller-fixture SHA-256 values are pinned in each expected file.

The numerical hand vectors supply independent checks of formulas. The larger
accepted-source traces supply regression evidence for nested diagnostics,
getters, errors and reference observations; they are not claimed as independent
mathematical proofs of every nested field. Tests compare both and serialized
field ordering. Dynamic callbacks are covered by the recorded runtime traces,
not claimed from the static import inventory alone.

## Installed package and isolation

One `npm pack` artifact is installed once through the existing consumer harness.
All three consumers use that exact installation and only public
`@rpg/core/kernel` Core imports. Each has a separate strict TypeScript NodeNext
program, native ESM execution and `skipLibCheck: false`. Installed lock integrity
matches pack SHA-512 integrity; installed Kernel JS/declarations match candidate
build bytes. Archive SHA-256:

`10d733ca0d767fb5c3658015d70550986707e7019da3a7d18606952803702ae4`

Fresh processes for each consumer and shared forward/reverse processes agree.
Every invocation also repeats and resets scenarios: 32 unique scenarios, 288
scenario execution instances in five installed runner processes. Caller-owned
HP/MP, equipment/buff toggles, deterministic RNG order, snapshots, getter/error
observations and aliases remain reproducible without cross-consumer state.
Only observation encoding is shared; each consumer owns its policies and API
orchestration. Numerical calculations call canonical Kernel APIs.

Installed verification took **44.07 seconds** locally, including packing,
installation and every existing consumer check. Per-program compile and runtime
measurements are recorded in the evidence, without performance thresholds.
