## Formulas and boundary policies

Damage uses minimum 0 / above-max allow and retains
`Math.max(0, Math.min(maximum, current - amount))`, applied magnitude
`Math.min(current, amount)`, defeated `current > 0 && after === 0`.
Thus 120 HP / max 100 / damage 10 -> after 100 / applied 10 despite net change 20.

Healing uses above-max reject / no increase from minimum; zero HP stays zero.
Mana uses above-max reject / increase from minimum allowed. Both keep
`Math.min(maximum, current + Math.min(amount, maximum - current))`, with
applied `after - current`. Clamping the increment before addition retains
MAX_VALUE behavior. Generic decrease uses `Math.min(current - minimum, amount)`.
Generic **allowed above-max increase can have negative applied**: 120 / max 100 / +10
-> after 100 / applied -20. This is explicitly tested; no contract redefinition occurs.

Normalization retains `Math.max(minimum, Math.min(maximum, current ?? maximum))`.
Omitted current initializes full; explicit zero stays zero, negative finite values
clamp, above-max clamps. Legacy returns only currentHp/currentMp.

Eligible regen retains the ordered expression:

```ts
Math.min(maximum, Math.max(current,
  Number((current + ratePerSecond * elapsedSeconds).toFixed(decimalPlaces))))
```

Maximum is read before the candidate. Legacy supplies precision 12 and seconds
converted once at its existing branch boundary. No candidate hoisting, epsilon,
remainder, recovery-transition substitution or extra lower clamp is added.
Living 1e-14 survives zero-rate rounding; overflow intermediates Infinity cap to
the finite maximum. Ineligible generic regen returns unchanged current without
reading maximum/minimum/rate/time/precision. The Legacy branch skips both regen
calls while preserving its initial validation reads.

The public primitives take caller-validated scalar inputs, not entity schemas.
Documented finite/sign/bounds preconditions remain caller-owned; no eager
revalidation of live post-validation getters is added. Transition's explicit
above-max reject policy throws ordinary Error `Current resource exceeds maximum`.
Legacy retains its earlier errors unchanged. Native getters/toFixed errors propagate.
Generic deterministic consumption requires stable/pure input accessors; readonly
does not imply copying/freezing, which remains v2.0.8 scope.

## Read timing, errors and unchanged gameplay

The four Legacy validation expressions/messages stay in place. Stats validation
still reads maxHp/maxMana/hpRegen/manaRegen before testing the array. Nonfinite
hp/mp checks short-circuit after that test. Forwarding accessors preserve the later
maximum reads: one for normalization's cap, a second only for omitted-current
fallback; then HP before MP. Regen maximum precedes rate and HP precedes MP.
Constructing inputs/result diagnostics adds no reads of the original Stats object.
Optional current is omitted when undefined to retain exactOptionalPropertyTypes;
public contracts remain unchanged.

Accepted golden scenarios cover mutation between phases, repeated getter reads,
validation error precedence and original thrown objects. elapsedMs is a captured
scalar argument: a caller getter runs before validation, and mutating its external
holder does not change the already captured value. Generic elapsedSeconds getter
order is tested separately without inventing a late-read Legacy callback contract.

No Skills source changed. Percentage amount resolution remains the live recipient
maximum times rate; lifesteal remains actual appliedDamage times rate. The actual
HP/MP transition has one owner. MP cost remains the existing Skill transaction.
Source/recipient pins, Root/Child receipts, replay/disposal/budgets, defeat handling,
positive-event gating and observer ordering retain the accepted owners.

The installed recovery example retains HP 75 / MP 58 / victim 0, exactly one action/capture/
roll, unchanged cooldown 1000, inert replay and this event order:
damage-applied, entity-defeated, mana-gained, effect-hit, healing-applied,
healing-applied, mana-gained. Its first observers still see source HP 50 / MP 48 / victim 0.
